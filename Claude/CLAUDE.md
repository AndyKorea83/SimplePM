## Цель проекта
Веб-приложение для управления проектами. Ключевая фича — отображение диаграммы Ганта.

# Дизайн
https://www.figma.com/design/cN7WtQB3J0ImRAWhIcGw3H/Gantt-diagram?node-id=3-929&t=XoFJKb6g7fRGTJB1-1

## Стек
- Backend: Go
- Frontend: React
- UI: дизайн берётся из Figma

## Деплой
- Прод: голое железо / bare-metal сервер, без контейнеризации (без Docker)
- Разработка: Windows

## Роадмап

Более подробные задачи находятся на github. Таски первого этапа в проекте PoC.

### Этап 1
- Прототип пользовательского интерфейса (UI по макетам из Figma)
- Данные для диаграммы Ганта загружаются из XML-файла

### Этап 2
- Интеграция с таск-трекером Gitea через базу данных MySQL
- Перенос существующего функционала системы (текущая реализация на PHP)
